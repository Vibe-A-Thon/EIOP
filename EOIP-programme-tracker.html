EOIP Programme Tracker

Evidence-gated progress for five EOIP / KnowGridFlow programmes: ASPEII (36 requirements, 216 clauses), Community & IP / CTAR (30 requirements, 62 acceptance clauses), IP — Warrant Engineering & neural-fabric inventions (239 requirements), Graph Neurons (36 requirements, 156 done-when checks) and the Wisdom Graph (200 requirements), plus 30 cross-programme decisions.

A tracker state is not proof. An item reaches EVIDENCED only with a commit, a native evidence path and its SHA-256, the exact command with exit code 0 and the programme's mandatory proof (ASPEII case ids and completion level ≥ L2, CIP JUnit ids, IP Evidence Pack + kill-switch + stub scan, Graph Neurons measured output, baselines and anti-stub probes). VERIFIED additionally needs an independent reviewer who re-ran it. File paths, symbols, test-file names and commit hashes on their own never qualify. verify_programme_ledger.mjs applies the same rules to the exported ledger and recomputes evidence digests in the repository.
