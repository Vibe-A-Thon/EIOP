# Historical Project Notes

This directory contains project/preview notes, including `PRD.md`. These notes are context, not the current runtime API contract, deployment guide or evidence ledger. Use the [documentation index](../docs/README.md) for maintained guidance.

Credential-named notes are potentially sensitive. Their values are intentionally excluded from the repository documentation inventory; do not copy them into guides, examples, logs or reports. Determine whether any such content needs removal/rotation through the normal security process without exposing it in documentation.

Before acting on an old note, compare it with current source, configuration and owning requirements. Preserve historical context rather than silently presenting it as an up-to-date production guarantee.
