## 4. How to read and maintain this matrix

- A capability is never marked missing if a supported backend provides it; such cases read 'available upstream / not integrated' in the backend column.
- Re-run `build_matrix.py` after any deep dive changes; coordinator judgements live in one place (the spec) so changes are reviewable.
- Priorities: P0 = correctness, lineage, idempotency, permission and tenant protection, repeatable vertical slice; P1 = high-value integration, governance, explainable retrieval/NL query, backend parity for core features; P2 = advanced reasoning/ML/federation; P3 = research (Master Prompt §13).
