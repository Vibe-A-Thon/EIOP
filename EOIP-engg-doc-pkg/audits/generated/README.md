# Generated Audit Artifacts Policy (CG-GAP-009 / DEC-05)

**Policy Notice:**
The files in this directory (`current-gap-report.json`, `current-gap-report.md`, `documentation-inventory.json`) are automatically derived evidence generated by `python -m scripts.documentation_audit --project-root .`.

The active project picture lives outside this generated directory: use
[root README](../../../README.md) for the operator overview and the owning requirement plans
and evidence ledgers for workstream status. Generated reports may lag the
working tree until the audit command is rerun. This directory is not a live
completion dashboard, and old backlog totals must not be reported as current
completion evidence.

Recent working-tree development that may not appear in regenerated artifacts yet
includes evidence-addressable GraphRAG, JSON-LD import/SHACL validation/round
trip checks, and semantic federation over local graph, file, REST, and
SQLite-backed JDBC-style sources with source policy enforcement.

## Normative Rules
1. **Derived Evidence:** These files represent snapshots of mechanical scanner passes across repository documentation, code symbols, routes, and test files.
2. **Never Source Requirements:** Generated audit artifacts must NEVER be treated as primary normative source requirements. Specifications include this package and the active root-level programmes indexed in [current documentation](../../../docs/README.md). [KGF-MASTER-BACKLOG.md](../../KGF-MASTER-BACKLOG.md) is one backlog, not the complete or independently verified status of every programme.
3. **Regeneration:** These files may be regenerated by running:
   ```powershell
   python -m scripts.documentation_audit --project-root .
   ```
4. **Retention:** Historical audits are preserved under `EOIP-engg-doc-pkg/audits/historical/` and remain immutable historical records.

## Separate Repository Inventory

The [repository inventory](../../../docs/generated/README.md) is produced by `scripts.repository_inventory`, not this generator. It records static file coverage, hashes and Python discovery without promoting requirement status. Neither tool's mechanical reads constitute full semantic review or live-system acceptance. Keep raw execution evidence in durable controlled storage, not solely in ignored scratch files.
