# Generated Audit Artifacts Policy (CG-GAP-009 / DEC-05)

**Policy Notice:**
The files in this directory (`current-gap-report.json`, `current-gap-report.md`, `documentation-inventory.json`) are automatically derived evidence generated by `python -m scripts.documentation_audit --project-root .`.

## Normative Rules
1. **Derived Evidence:** These files represent snapshots of mechanical scanner passes across repository documentation, code symbols, routes, and test files.
2. **Never Source Requirements:** Generated audit artifacts must NEVER be treated as primary normative source requirements. The primary specifications remain in `EOIP-engg-doc-pkg/*.md`, and active completion tracking is maintained in [KGF-MASTER-BACKLOG.md](../../KGF-MASTER-BACKLOG.md).
3. **Regeneration:** These files may be regenerated at any time by running:
   ```powershell
   python -m scripts.documentation_audit --project-root .
   ```
4. **Retention:** Historical audits are preserved under `EOIP-engg-doc-pkg/audits/historical/` and remain immutable historical records.
