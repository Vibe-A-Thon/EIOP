# Agent Runbook
- Branch naming: onboarding/<role>-YYYYMMDD or feature/<ticket-ID>
- Commit message format: <ticket-ID>: short description or onboarding: short description
- Ticket file name: ticket-YYYYMMDD-NNN.md
- Update rules: update todo-status.md and checklist.md on every ticket status change
- Handoff: append Handoff block to memory.md and context.md before session end
