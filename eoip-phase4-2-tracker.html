About this board

The board and eoip-phase4-requirements.md carry the same items. The AI developer agent ticks boxes in the Markdown; use Progress, then Import to load them here. Use For the agent, then Download updated Markdown to hand back a file that includes your ticks and your Accept, Defer and Reject decisions. That download is rebuilt from the Markdown text embedded when this page was generated, so if you edit the Markdown by hand, import it here rather than relying on the download.

Progress is saved in this browser. Use Export JSON to keep a copy or move it to another browser. If you used the previous eoip-phase4-tracker.html in this browser, its statuses and criteria are imported automatically the first time this page opens.

When a status is set to Done, all criteria on that item are ticked. Ticking the last criterion marks the item Done, ticking the first moves it to In progress, and unticking one on a Done item moves it back to In progress. Turn off Review-added criteria on the Board to ignore the extra criteria the review added.
